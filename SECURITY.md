# Security Policy

This is a portfolio project, not a company with a formal security program —
but if you find a real issue (a module default that creates something
insecure, an IAM policy broader than documented, a secret handled
carelessly), please report it rather than filing it as a public bug with
exploit details attached.

## Supported versions

Only the latest tagged release gets fixes. There is no long-term-support
branch.

## Reporting

Use GitHub's private vulnerability reporting (Security tab \u2192 Report a
vulnerability) for anything sensitive. For anything else, a regular issue is
fine.
